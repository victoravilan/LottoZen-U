Crear tu Keystore de Firma (CRÍTICO)

Este paso es OBLIGATORIO. Sin un keystore propio, no puedes publicar en Google Play. El keystore actual usa el debug keystore que NO es válido para publicación.

Opción A: Crear keystore desde línea de comandos

Abre una terminal (Git Bash o Command Prompt) y ejecuta:

keytool -genkey -v -keystore lottozen-release.keystore -alias lottozen -keyalg RSA -keysize 2048 -validity 10000

Te pedirá:

  • Keystore password: Elige una contraseña segura y GUÁRDALA
  • Re-enter password: Repítela
  • First and last name: Victor M.F. Avilan
  • Organizational unit: Desarrollo
  • Organization name: LottoZen Ultra
  • City: Tu ciudad
  • State: Tu provincia/estado
  • Country code: ES (para España)
  • Key password for lottozen: Puede ser la misma o diferente - GUÁRDALA

Opción B: Crear keystore desde Android Studio (más fácil)

  1. En Android Studio: Build → Generate Signed Bundle / APK
  2. Selecciona Android App Bundle → Next
  3. En "Key store path", haz clic en "Create new..."
  4. Elige dónde guardar el keystore (ej: C:\keystores\lottozen-release.keystore)
  5. Completa todos los campos (password, alias, nombre, organización, etc.)
  6. Haz clic en OK

Configurar el keystore en build.gradle

Una vez tengas tu keystore, edita android/app/build.gradle y reemplaza el signingConfigs.release:

signingConfigs { release { storeFile file('C:/keystores/lottozen-release.keystore') storePassword 'TU_PASSWORD_KEystore' keyAlias 'lottozen' keyPassword 'TU_PASSWORD_KEY' } }
GUARDA TU KEYSTORE EN UN LUGAR SEGURO. Si pierdes el keystore, NUNCA podrás actualizar la app en Google Play con el mismo package name. Haz una copia de seguridad.

Generar el AAB (Android App Bundle)

Google Play requiere formato .aab (no .apk) para nuevas apps.

Opción A: Desde Android Studio (recomendado)

  1. Build → Generate Signed Bundle / APK
  2. Selecciona Android App Bundle → Next
  3. Selecciona tu keystore e ingresa las contraseñas → Next
  4. Selecciona release → Finish
  5. Espera a que compile (puede tardar 2-5 minutos)
  6. Cuando termine, haz clic en "locate" para encontrar el archivo .aab

Opción B: Desde línea de comandos

Primero asegúrate de haber hecho el build web y sync:

cd "C:\Users\Victor M.F. Avilan\WorkBuddy AI\2026-10-30-11-58-06\LottoZen-Ultra" npm run build cp -r dist/* android/app/src/main/assets/ cd android ./gradlew bundleRelease

El archivo .aab estará en:

android/app/build/outputs/bundle/release/app-release.aab
El AAB generado será de aproximadamente 300-500 KB (app muy ligera).

Clasificación de Contenido (Content Rating)

  1. Ve a Configurar tu app → Clasificación de contenido
  2. Selecciona "Iniciar cuestionario"
  3. Responde el cuestionario IARC:
P: ¿La app contiene violencia? → No P: ¿Contiene contenido sexual? → No P: ¿Contiene lenguaje soez? → No P: ¿Contiene apuestas con dinero real? → No (es solo predictiva, no permite apostar) P: ¿La app permite compras integradas? → No P: ¿Contiene anuncios? → No P: ¿Recolecta datos personales? → No (solo localStorage en dispositivo)

Con estas respuestas, la app recibirá clasificación PEGI 3+ o Everyone.

Aunque la app trata sobre lotería, NO permite apostar dinero real dentro de la app, por lo que NO se considera "Gambling app". Es una herramienta de entretenimiento/numerología.

Audiencia Objetivo y Datos de Seguridad

Audiencia objetivo

  1. Ve a Configurar tu app → Audiencia objetivo
  2. Edad objetivo: 18+ o "Todas las edades" (la app no tiene contenido inapropiado)
  3. Selecciona que la app NO está dirigida a niños menores de 13

Sección de datos (Data Safety)

  1. Ve a Configurar tu app → Seguridad de datos
  2. Selecciona "No, la app no recolecta ni comparte datos"
  3. (Importante: aunque la app usa localStorage, Google no considera esto como "data collection" porque no se transmite a servidores)
Al indicar que no recolectas datos, simplificas enormemente el proceso de aprobación.

Subir el AAB a Google Play

  1. Ve a Publicar tu app → Producción (o "Production")

  3. En "App bundles", arrastra o sube tu archivo app-release.aab
  4. Espera a que se procese (1-2 minutos)
  5. En "Notas de la versión", escribe:
Versión 2.1.0 - Release inicial LottoZen Ultra - App predictiva de numerología cuántica para análisis de lotería. Características principales: - 18 sistemas integrados (13 cósmicos + 5 cuánticos) - 9 loterías soportadas - Optimizador estratégico con biorritmos - Motor cuántico con superposición, entrelazamiento y tiempo en espiral - Funciona 100% offline - Solo entretenimiento, +18 años

  • Haz clic en "Revisar versión"
  • Haz clic en "Iniciar implementación en producción"

    Revisión de Google y Publicación

    Después de subir el AAB, Google revisará la app. El proceso:

    • Revisión automática: 1-2 horas (escaneo de malware, políticas)
    • Revisión manual: 1-7 días (un revisor humano prueba la app)
    • Primera publicación: Puede tardar hasta 7 días para apps nuevas
    • Actualizaciones futuras: Generalmente 1-3 días
    POSIBLES PROBLEMAS Y SOLUCIONES:
    • "Viola política de apuestas": Asegúrate de que la app NO permite apostar dinero real. Es solo predictiva/numerológica. La descripción debe decir claramente "entretenimiento".
    • "Política de privacidad faltante": La URL debe ser accesible públicamente
    • "Icono no cumple": El icono 512x512 debe ser PNG sin transparencia
    • "Targeting API baja": Ya configurado a API 35 (cumple)
    Cuando la app sea aprobada, aparecerá automáticamente en Google Play Store con la URL: https://play.google.com/store/apps/details?id=com.lottozen.ultra
